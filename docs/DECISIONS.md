# Decisiones

Una línea por decisión: qué se decidió y qué implica. Fecha de todas: 2026-09-28, salvo que se indique.

| ID   | Tema                       | Decisión                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Consecuencia                                                                                                                                 |
| ---- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | Stack                      | Monorepo pnpm, TypeScript estricto. `core` (zod, flatbush, d3-delaunay, dxf-parser), `engine` (Three.js), `workers` (Comlink, pdf-lib), `web` (React 19, Vite, Zustand, ECharts), Vitest                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Un lenguaje para cálculo, UI y tests. Solo licencias permisivas (NF-15)                                                                      |
| D-02 | Dónde corre el cálculo     | Todo en el navegador; lo pesado en Web Workers. `core` es TS puro y corre también en Node                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Sin servidor; un backend futuro puede importar `core` tal cual                                                                               |
| D-03 | Persistencia               | JSON versionado exportable; IndexedDB con autoguardado (1 versión/min, 20 por proyecto, `apps/web/src/persistence/`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Funciona sin conexión; sin multiusuario hasta F5                                                                                             |
| D-04 | Dibujo                     | WebGL con Three.js, InstancedMesh, render a demanda, coordenadas relativas al origen (float32). Canvas2D prohibido                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | 60 fps con 5.000 taladros, probado con el fixture de rendimiento                                                                             |
| D-05 | Formato de proyecto        | JSON con `format`, `schemaVersion`, `savedAt`, `project`, validado con zod. Cada cambio de esquema sube `SCHEMA_VERSION` y agrega una migración con test (`core/src/io/projectFile.ts`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Ida y vuelta sin pérdidas; se leen todas las versiones anteriores y el formato `blastlab-project`                                            |
| D-06 | Pruebas                    | Valor esperado de un caso de referencia (CR-xx) o de la fuente, nunca de la misma fórmula del código. El test cita el caso y el paso. Cobertura ≥ 85 % en `core`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Una fórmula llega a R3 solo con un test así                                                                                                  |
| D-07 | Prototipo                  | Se reutiliza todo lo de BlastLab (fases 0–9) y se regulariza hito a hito, sin reescribir                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | El código de F2 existía pero no cuenta como verificado hasta reproducir sus casos                                                            |
| D-08 | Backend                    | Diferido. Usuarios, roles, comentarios, auditoría e historial en servidor pasan a F5. **Levantada por D-14** (2026-09-30)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | R-25, H-801, UC-09 y NF-07 abiertos hasta F5                                                                                                 |
| D-09 | Nombre                     | Cronos (antes BlastLab): paquetes `@cronos/*`, UI y `format: 'cronos-project'`. Las capas DXF conservan el prefijo `BL_`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Verificar el nombre antes de distribuir (F5)                                                                                                 |
| D-10 | Unidades                   | SI estricto interno (m, kg, s, rad, Pa, J/kg, kg/m³, m/s). Los casos en ms o mm/s se convierten en el test. Nombres en código: `loadingFactor` [kg/m³], `powderFactor` [kg/kg, se muestra en kg/t], `energyFactor` [J/kg, se muestra en MJ/t]                                                                                                                                                                                                                                                                                                                                                                                                                    | Conversión solo en presentación; tolerancia de 1e-9 s para tiempos «exactos»                                                                 |
| D-11 | Idiomas                    | Sin librería: diccionarios por área en `apps/web/src/i18n/ns/*.ts`, inglés con `satisfies` (falta una clave → no compila). El núcleo devuelve `id` y `params` y se traduce en `i18n/coreText.ts`; el motor con `setText`; el PDF con su propio diccionario                                                                                                                                                                                                                                                                                                                                                                                                       | Todo texto visible pasa por `t()`                                                                                                            |
| D-12 | Dudas de dominio           | (2026-09-29) Primero se busca la fuente (web, libros, `docs/theory/`). Si no aparece, se toma un supuesto razonable como **parámetro editable** y se anota en `docs/QUESTIONS.md` («Supuestos»). No se detiene el trabajo por preguntas                                                                                                                                                                                                                                                                                                                                                                                                                          | Menos preguntas al ingeniero; cada supuesto queda visible y se revisa en la siguiente evaluación                                             |
| D-13 | Documentos                 | (2026-09-29) Nombres de archivo en inglés y mayúsculas, contenido en español. Pocos archivos: `ROADMAP`, `RULES`, `QUESTIONS`, `DECISIONS`, `REPORTS`, `ARCHITECTURE`, `DEPLOY`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `docs/theory/` conserva el contenido del ingeniero; solo se renombraron sus archivos                                                         |
| D-14 | Backend, login e historial | (2026-09-30) Se adelantan D0–D2 de F5. Servidor Node (`apps/server`: Fastify, Better Auth, PostgreSQL con Kysely) que importa `@cronos/core` para validar y comparar proyectos; contratos HTTP con zod en `packages/api`. **Empresa > Minas > Proyectos**: los roles de la guía `§1.4` (administrador, diseñador, revisor) se asignan en la empresa y una mina puede restringir su acceso. Cada proyecto guarda **versiones inmutables al publicar** (autor, fecha, mensaje, resumen de cambios); el autoguardado local es el borrador; restaurar crea una versión nueva; concurrencia optimista (409). Sin `VITE_API_URL` la app funciona como antes, sin login | El modelo de dominio no cambia (esquema v10). Mismo origen vía nginx (`/api/`), cookie `httpOnly`. Credenciales solo en variables de entorno |
